# 🌿 SafeSpace AI

An agentic AI mental-health support assistant. A LangGraph agent follows the ReAct pattern (observe, reason, act, evaluate) to classify risk, choose tools and respond safely.

**Stack:** LangGraph · LangChain · FastAPI · Gradio · MedGemma 4B · Llama 3.2 · Ollama · Twilio · OpenStreetMap

## ⚠️ Important
SafeSpace AI is a student project and **not a replacement for professional help**.
If you are in danger or thinking about harming yourself, call **112** (EU) or your local emergency number.
In Germany you can also reach the Telefonseelsorge 24/7 at **0800 111 0 111**.

This public demo runs on a free CPU server, so answers can take 30 to 90 seconds.
Emergency calling via Twilio is disabled in the demo.
